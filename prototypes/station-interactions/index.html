Micro-Interaction Lab

Five small tests for interface feedback. Each experiment isolates one decision instead of recreating the workstation.

01 / Physical response

Pads

Decision under test: can a flat screen communicate the short travel, edge compression and controlled under-light of a rubber pad?

Input Pointer, touch or keyboard. Hold a pad, then release it.

02 / Control → response

ZOLA-X

Decision under test: can one focused control per view make the display response feel direct, technical and immediately understandable?

OSC 1 / BLOOM 28% POSITION

Input Each view exposes one display-linked control: POSITION, CUTOFF, ATTACK or PHASE.

04 / Direct feedback

Laser

Decision under test: slicing feedback should be immediate and precise. A short hot line confirms the action; it does not become a light show.

Input Move for playhead · click waveform or a numbered marker to audition visual feedback.

05 / Discrete state

Seq

Decision under test: active steps should read as committed musical events, not selected cells in a data table.

Pattern 01-A
Pad 12345678 01 02 03 04

Input Toggle individual steps. The playhead is visual only and carries no timing engine.
